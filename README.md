# Sayan Mondal — AI Content Strategist & Prompt Engineer

A space-themed portfolio built with Next.js, React Three Fiber, and Framer Motion. Scroll-driven background animations, a tilting starfield, and a blackhole hero.

## Getting Started

## Scripts

| Script            | Description            |
| ----------------- | ---------------------- |
| `npm run dev`     | Start the dev server   |
| `npm run build`   | Production build       |
| `npm run start`   | Serve the build        |
| `npm run lint`    | Lint the codebase      |

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- React Three Fiber + Drei + Three.js

## Sections

- Hero — name, headline, and blackhole parallax background
- Experience — AI content strategy, prompt engineering, and education roles
- Education — degrees and certifications
- Skills — prompt engineering and generative AI tooling
- Encryption — design moment with a scroll-driven background
